# CC-GAN

This repository contains code associated with the paper "CC-GAN: Coronary Artery 3D Reconstruction from Two X-ray Views with Mamba-based Topology-Aware Generator and Dual-Domain Discriminator", accepted by IEEE JBHI.

## Environment

* **Operating System**: Ubuntu 22.04
* **Python**: = 3.10
* **PyTorch**: = 2.4.1
* **mamba-ssm**: = v2.2.6.post3
* **tigre**

## Acknowledgements

The implementation of CC-GAN is revised based on [DeepCA](https://arxiv.org/abs/2407.14616). We thank the authors for their excellent work.
